## Usage guidelines

### Website
- **Navbar** — use `gleric-logo-wordmark-white.svg` at `h-8 md:h-10`
- **Hero** — full lockup or wordmark at larger scale
- **Footer** — wordmark or large text lockup rendered via CSS

### Print & merch (shirts, caps, stationery)
- Always send **SVG or PDF** to the printer — never a PNG or screenshot
- The printer may ask you to **convert text and strokes to outlines** — most tools (Illustrator, Inkscape, Affinity Designer) can do this via "Expand" or "Object to Path"
- Use the **white** version on dark fabric; **black** version on light fabric or paper
- Minimum clear space: leave at least the height of the "G" letter on all sides

### Color
- White versions are flat solid `#f4f4f4` — no gradients, so the mark stays a single spot color for screen printing
- Black versions are flat solid `#0a0a0a`
- Service list and the divider use opacity (not a second color) for hierarchy — this survives a black/white print conversion cleanly

### Don't
- Don't stretch or distort the logo
- Don't place the white logo on a light background
- Don't add gradients, drop shadows, or effects in-layout
- Don't use raster (PNG/JPG) exports for print jobs over A5 size
